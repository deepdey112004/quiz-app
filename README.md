# quiz-app
A simple quiz application built using HTML, CSS, and JavaScript.

## Project Description
Quiz App is a simple web-based quiz application built using HTML, CSS, and JavaScript. 
The application displays multiple-choice questions and allows users to select answers. 
At the end of the quiz, the application calculates and shows the final score.

## Features
- Multiple choice quiz questions
- Interactive user interface
- Instant answer selection
- Next question navigation
- Score display at the end

## Technologies Used
This project is developed using:

- HTML – For creating the structure of the web page
- CSS – For styling and designing the interface
- JavaScript – For quiz logic and user interaction

## File Explanation

### index.html
This file contains the structure of the quiz application. It includes the quiz container, question display, answer options, and buttons.

### style.css
This file is used to style the quiz application. It controls colors, layout, fonts, and overall appearance of the application.

### script.js
This file contains the main logic of the quiz application such as:
- Storing quiz questions
- Displaying questions
- Checking selected answers
- Moving to the next question
- Calculating and displaying the final score

## How the Application Works

1. The application loads the first quiz question.
2. The user selects an answer from the available options.
3. JavaScript checks whether the selected answer is correct.
4. The user clicks the "Next" button to move to the next question.
5. After all questions are answered, the application shows the final score.

## How to Run the Project

Follow these steps to run the project:

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in any web browser

The quiz application will start running in the browser.
